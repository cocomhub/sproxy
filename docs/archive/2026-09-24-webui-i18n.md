# WebUI i18n 多语言 — 归档

> **归档说明**：原文 `docs/designs/2026-09-24-webui-i18n.md` 已于 2026-11-14 归档。
> 现行行为见 `docs/api.md` §GET /ui/。本文件只保留**设计意图 / 取舍 / 外部契约 / 仍有效的判断**。

## 背景 / 目标
`index.html` 硬编码 `<html lang="zh-CN">`、全部文案中文；`app.js` 动态文案（toast/confirm/prompt/空态）
全中文，无 i18n 框架。目标：轻量 i18n（**零框架**）——新增 `web/static/i18n.js`，zh/en 双语；
**zh 为默认与兜底**，保证既有中文 UI 零回归。

## 定案与取舍（仍有效）
1. **零框架、纯前端静态文件**：字典 + `t()`/`fmt()` 取词插值 + `lang()`/`setLang()` + `applyStaticI18n()`，
   走嵌入式 static FS，CSP `script-src 'self'` 已满足（无需改服务端头）。
2. **zh 逐字保留现状文案**：构造上不变 ⇒ 既有中文 e2e 断言天然继续通过（零回归护栏）。
3. **缺 key 可发现**：`t()` 落空回落 zh → 仍缺返回 key 原文（页面可见占位，便于定位漏译）。
4. **语言解析优先级**：`localStorage['sproxy_lang']` > `navigator.language`（`zh*`→zh，其余→en）> 默认 `zh`；
   `setLang` 写 localStorage + 同步 `<html lang>` + 派发 `i18n:changed` 事件。
5. **不追求 100%**：先覆盖 `index.html` 全部静态文案 + `app.js` 高频动态文案；低频弹窗/表格内文案
   可后续片补（设计明示的收敛边界）。
6. **新 JS 必须进 Makefile `web-test`**：否则 R10 门禁红。

## 外部契约 / 踩坑
- 静态节点用 `data-i18n`（textContent）/ `data-i18n-placeholder`（placeholder 属性）批量替换；
  用户数据（文件名等）**不翻译**，仅作 `{name}` 插值变量（XSS 由调用方 `escHtml` 负责）。
- localStorage 不可用（隐私模式）⇒ try/catch 回落 `navigator.language`；插值缺变量 ⇒ 保留 `{name}` 原样。
- 语言切换后：监听 `i18n:changed` 的视图重拉重渲染；未监听的重进页面生效（v1 接受）。

## 落地指针
- `web/static/i18n.js`（`I18N`：`dicts` zh/en、`t` / `fmt` / `lang` / `setLang` / `applyStaticI18n`）；
  `web/static/index.html`（`data-i18n` 节点 + `#lang-toggle`）、`web/static/app.js`（setLang 接线 + 事件监听）。
- 测试：`web/static/i18n.test.js`（`node --test`，登记 Makefile `web-test`）、`web/e2e/i18n_e2e_test.go`
  （Playwright 语言切换零回归）。
