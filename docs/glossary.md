# Mesh 场景术语表

本文档统一 mesh 内网穿透的部署角色术语，避免出现具体机器/地域信息。

## 角色

| 术语 | 定义 | 网络位置 | 典型职责 |
|---|---|---|---|
| **公网服务器** | 有公网 IP、可被所有节点入站访问的服务器 | 公网 | 运行 hub 中继（注册/寻址/信令/兜底中继）；也可同时作为目标节点 |
| **本地端** | 需要访问远端服务的客户端设备 | 私有 NAT（出站可上网） | `mesh connect` / `relay dial` / `p2p connect` |
| **中继端** | 位于第二个网络、可稳定访问公网服务器的节点 | 私有 NAT（出站可上网） | `relay start`（叶子/出口），替本地端出站访问目标 |
| **目标节点** | 承载目标服务的节点 | 公网或私有 | 宣告服务（`--service`），被访问方 |
| **出口节点** | 开启 `--dial-allow` 的叶子，可代其他节点出站拨号 | 任意 | 替访问方出站连接目标地址 |

> **约定**：同一节点可同时担任多角色（如中继端兼出口节点、公网服务器兼目标节点）；
> 角色描述的是**职责**而非物理设备，一个进程/一台机器可以身兼数职。

## 网络关系

```
[ 本地端 ] ──客户端侧 NAT──┐
                           ▼ 出站 WSS（注册/信令）
[ 中继端 ] ──中继端侧 NAT──┼─► [ 公网服务器 ] ◄─┐
                           │    hub 中继       │
                           ▼                  │ 出站 WSS
[ 目标节点 ] ──公网────────┘  被访问方 ◄───────┘
```

- **客户端侧**：本地端所在网络（通常无法被公网主动访问）
- **中继端侧**：中继端所在网络（通常无法被公网主动访问，但出站稳定）

## 术语映射

| 场景化术语 | 可能的具体称谓（非正式） |
|---|---|
| 本地端 | 私有网络设备、访问客户端 |
| 中继端 | 私有网络设备、出口网关、跳板节点 |
| 公网服务器 | 公网可达服务器、hub 宿主机 |
| 目标节点 | 公网或私有网络的服务端 |

## 约定

- 文档与示例中一律使用上述角色术语，不出现具体设备名、厂商、地域。
- 示例地址用 `example-host:port` / `127.0.0.1:port` 占位。
