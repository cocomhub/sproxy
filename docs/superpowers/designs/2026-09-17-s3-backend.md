## 目标

实现 **S3 对象存储后端**：把任意 S3 兼容对象存储（AWS S3 / MinIO / COS / OSS）作为 sproxy 外部卷——`sync.FS` 7 方法经 S3 API（ListObjectsV2/GetObject/PutObject/CopyObject/DeleteObject）映射，经 V3 plugin（`RegisterBackend("s3")`）接入系统盘（volumes[]）与用户卷。

## go.mod 隔离（用户明示）

S3 依赖第三方 SDK（minio-go），放**独立 Go module**（仿 baidupcs）：

```
pkg/s3/                    # 独立 module
  go.mod                   # module github.com/cocomhub/sproxy/pkg/s3
  s3_fs.go                 # S3FS：sync.FS 7 方法（minio-go 客户端）
  s3_fs_test.go
  backend.go               # RegisterBackend("s3") + Extra 解析
  backend_test.go

go.work 加 ./pkg/s3
主 go.mod 加 replace github.com/cocomhub/sproxy/pkg/s3 => ./pkg/s3
```

- **SDK 选择：minio-go**（轻量纯 Go、API 稳定、社区活跃——符合仓库第三方依赖规则；支持 AWS S3/MinIO/COS/OSS 兼容）
- 独立 module 隔离第三方依赖（主仓不直接依赖 minio-go；lint/addlicense 不污染 SDK 相关文件——只含自有代码）
- GOWORK=off 独立构建/测试验证（子 module 硬规则）

## 核心设计

### 1. S3FS（sync.FS 实现）

```
pkg/s3/s3_fs.go
方法映射（S3 API）：
  ListDir(path)   → ListObjectsV2(prefix=path+"/", delimiter="/") → 子条目（CommonPrefixes 目录 + Contents 文件）
  Stat(path)      → HeadObject（不存在 → nil）| 目录 = ListObjectsV2 前缀探测
  OpenRead(path)  → GetObject → io.ReadCloser
  WriteFile(path, r, size, mtime) → PutObject
  Rename(from,to) → CopyObject + DeleteObject（S3 无 MOVE）
  Delete(path)    → DeleteObject（幂等）
  MakeDir(path)   → 零字节占位对象（key=path+"/"；S3 无目录纯概念）
```

- **无目录概念**（与 baidupcs 类似）：目录 = 前缀；ListDir 用 delimiter="/" 单层列举（CommonPrefixes + Contents）
- HTTP 客户端：minio-go 自带（每实例独立，不共享）
- 认证：AccessKey/SecretKey + endpoint + bucket + region
- 路径：bucket + key（prefix 根）

### 2. V3 plugin 接入（RegisterBackend("s3")）

```
newS3Backend(ctx, v volume.Volume) (registry.ExternalBackend, error)：
  v.Extra 读：endpoint（必填）、bucket（必填）、access_key/secret_key（必填）、region（可选）、
             use_ssl（可选 bool）、local_root（可选中间态）
  → minio.New(...) → S3FS 构造
  → ExternalBackend{FS() = S3FS, Close() = 关连接}

config volumes[] type=s3 校验（extra.endpoint/bucket/access_key/secret_key 必填）
用户卷 type=s3 复用现有 API
```

### 3. syncmgr 集成

- kind=volume 已通用（WebDAV 时做）——S3 卷 `remote.volume` 查 Set.External 即可，**零额外改动**
- Web 下拉：backend 列表 API（GET /api/backends）已动态——s3 自动出现，**零前端改动**
