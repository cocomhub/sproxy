## 功能摘要

UDP 端口映射（`sclient udp map`）：本地 UDP 端口经 mesh（webrtc 直连 + mux
FrameDatagram 数据报帧）映射到出口节点的远程 UDP 地址，双向转发。出口节点
（`mesh node` 的 relay.Serve）把该 mux 作为 UDP 数据报通道，收到数据报转发到目标
UDP 地址，目标响应原路回传。

## 架构决策

1. **mux FrameDatagram 正交于流**：UDP 数据报按消息边界传输（不拆流、不流控），负载
   `[4B flowID][datagram]`（单端口映射 flowID=0；未来可扩多流五元组）。经 writeCh 串行化
   （与流写共享单写者，防并发写 xfer.Conn），isRaw 直发（UDP 尽力而为不重传）。
2. **出口 UDP 处理在 relay.Serve**：UDP 映射帧 `{"udp": addr}` 与 dial 帧同属出口模式，
   `--dial-allow` 门控。`handleUDPMap` 用**单 UDP 协程**串行处理转发与响应（读用短
   deadline 周期性让出给待发数据），消除 handler/读/关闭并发访问 conn 的竞态。
3. **`sclient udp map` 本地侧**：本地 UDP 监听 → 数据报经 mesh（webrtc mux + datagram）
   到出口；出口响应 → datagram handler → 回传本地 UDP 客户端（记录来源地址）。
4. **支持 hub/mDNS 两种信令**：`--mdns` 直连信令 / hub AutoRegister；hub 中继回落暂
   不支持 UDP（webrtc 路径即可满足 DoD）。

## 关键坑

1. **单 UDP 协程死锁**：初版用 `select{<-sendCh; default}` + 阻塞 `conn.Read`——协程阻塞在
   `conn.Read` 时无法消费 sendCh，永远不写数据到目标（死锁，echo 不响应）。修复：读用
   50ms deadline 周期性让出给 sendCh（UDP 转发延迟可忽略）。
2. **datagramHandler 竞态**：readLoop 读、relay 运行期 SetDatagramHandler 写 → RWMutex
   保护（`getDatagramHandler`）。
3. **UDP conn 并发访问竞态**：handler 写 + 响应读 + 关闭并发 → 单 UDP 协程串行化
   （conn 在协程内部 defer Close，无并发 Close 竞态）。
4. **loopback 信令端点校验**：手动验证时 `--signal-addr 127.0.0.1:0` 广播 loopback 被
   `ValidateSignalAddr` 生产模式拒绝（正确安全边界）；用默认 LAN IP 信令。

## 整体代码审核（code-review 多 agent）发现与修复

- **H1（必须）Ctrl+C 收尾死锁**：defer 顺序致 `control.Close()` 先执行，writeCh 满时
  `stream.Close` 永久阻塞 → `m.Close` 永不执行。修复：`control.Abort()`（非阻塞）+ defer
  顺序 m.Close 先。
- **H2（必须）客户端静默永久挂起**：唯一出口 `<-ctx.Done()`，mux 死亡/出口拒绝目标时
  无错误输出永久挂起。修复：select 监听 `m.Done()` → 报错退出。
- **H3（必须）SendDatagram writeCh 满阻塞（双向头阻塞）**：修复：加 default 丢弃
  （`ErrDatagramDrop`，UDP 语义），调用方 log+continue 不终止。
- **H4（必须）出口 sendCh 饿死 → 单向化**：单协程 `continue` 优先排空 sendCh，出站持续
  时永不读响应。修复：重写为并发读协程 + 写路径（conn.Read 与 WriteToUDP 并发安全），
  mutex 串行化 Close。
- **H5（必须）sendFrame isRaw 失败关整个 mux**：数据报高频瞬时失败连带杀掉同 mux TCP
  流。修复：`writeMsg.datagram` 标记，数据报发送失败只丢弃不关 mux。
- **H6（建议）出口 connected socket 丢多源响应**：DialUDP 丢弃源不一致响应。修复：
  `ListenUDP`+`WriteToUDP`（支持 TFTP/游戏协议/多 A 记录回包）。
- **H7（建议）读错误白名单不对称**：EHOSTUNREACH/ENETUNREACH 未列白名单。修复：
  `isUDPMomentaryErr` 扩全。
- **H8（建议）udp map 收尾 <-udpDone 无界**：SendDatagram drop 后读协程不悬停（H3 连带
  修复）。
- **H9（建议）svcErr 被吞**：打 Warn 供排查。
- **H10（建议）帧字段嗅探歧义**：统一解析 udp/dial/http 三帧，仅"命中一种"分派（防
  udp+method 双字段帧被劫持）。

**文档化设计取舍**：clientAddr 单槽（单客户端语义）；datagramHandler 单槽（CLI 每命令
独立 mux）；响应并发 goroutine 乱序（UDP 不保证有序）；OpenUDPMux 无重试/回落（UDP 需
mux，错误信息清晰）。
