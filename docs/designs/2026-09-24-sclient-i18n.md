# sclient 多语言输出（11.10-⑥）

## 背景/目标
- 现状：`cmd/sclient/output.go` 的 `TextFormatter` 全部文案中文硬编码（"暂无分享链接"、"分享链接:"、"字节"、"已设置"、"服务器统计（自启动以来）" 等）；`boolStr` 同样硬编码。JSONFormatter 输出键是英文（机器契约，不动）。
- 目标：Text 模式文案 i18n（LC_ALL/LC_MESSAGES/LANG 感知，默认中文零变化）；表格**列头**（TOKEN/FILENAME 等）与数据保持稳定；不引第三方库（标准库 `text/template` 或直接字典查找）。

## 组件与接口
- `cmd/sclient/internal/i18n`（新包，纯标准库）：
  - `T(string) string` / `F(string, args ...any) string`：字典键→翻译（fmt 占位符 `%s/%d` 复用）。
  - `Locale() string`：`LC_ALL` > `LC_MESSAGES` > `LANG` 环境变量探测（`os.Getenv`，空跳过）；`zh*`/`C`/空 → zh-CN（默认）；`en*` → en；其余回退 en（文档标注）。
  - `dict`：`map[string]map[string]string`（zh-CN / en 两表）；en 表补全**现有全部**中文文案；缺失键回退原文（fail-open 显示原中文，日志不输出——CLI 无 slog 依赖，直接返回原串）。
- `cmd/sclient/output.go`：
  - `TextFormatter` 内所有 `fmt.Fprintf` 中文字面量 → `i18n.F`；`boolStr` → `i18n.T`。
  - **列宽与表格布局不变**（`%-36s %-40s ...` 原样，只换文案词）；文件名/URL/大小等数据不翻译。
  - `buildFormatterWithWriter` 无需改（JSON 模式不动）。
- 测试挂钩：`i18n.Locale` 包级函数可注入（`var lookupEnv = os.Getenv`，测试 `t.Setenv` 覆盖——受 R18 序列豁免规则保护）。

## 数据流
CLI 启动 → 首次 Text 输出时 `i18n` 按环境探测一次 locale（包级 once，缓存）→ 各 `PrintXxx` 调用 `i18n.T/F` 取词 → 输出。LC_ALL 变化需重启 sclient（文档标注）。

## 错误处理
- 字典键不存在/翻译缺失 → 返回原键（中文原文），绝不 panic、绝不空串（空串会破坏表格布局）。
- 环境变量含非法 locale（如 `LC_ALL=foo`）→ 回退 zh-CN（默认语义）。
- `fmt.Fprintf` 参数数量错误仍由 fmt 自身处理（与现状一致，不新增错误路径）。

## 测试+变异点
- `i18n` 包单测：locale 探测优先级/回退/非法值；字典全键遍历（en 表与 zh 表键集合必须相等——门禁式测试防漏译）；`F` 占位符正确性。
- `output.go` 现有测试（若有 golden 断言）需同步更新或按「语言=默认中文」保持绿；新增 `LANG=en` 下 `PrintShareList`/`PrintStat` 输出含英文词的断言。
- 变异验证：① 删 en 表某个键 → 键集相等测试红；② Locale 优先级写反（LC_ALL 被 LANG 覆盖）→ 探测测试红；③ `T` 返回空串 → 布局测试红。

## 片划分
- 片1：`internal/i18n` 包 + 字典全量迁移（output.go 逐处替换）+ 单测（一次 PR）。
- 片2：docs/cli.md 增「语言环境变量」小节；如需双语 README 片段可并入。

## 风险与零回归
- 默认环境无 LC_ALL/LANG（或 C/zh）→ 逐字旧中文输出（golden 锁定）；JSON 契约零改动（机器解析不破）；不新增依赖（符合依赖策略）；列宽/排序/对齐格式符不动，避免回归行宽差异。
