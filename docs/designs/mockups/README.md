# Web UI 设计稿（v3）

单文件、零依赖、CSP 友好的可交互原型，用于评审 **A/B/C 三套结构方案**与交互规范，不是产品代码。

- 原型：`webui-v2-prototype.html`（浏览器直接打开，`file://` 即可）
- 对比度审计：`audit_contrast.py`

## 怎么用

右下角「设计稿」控制条：

| 控件 | 作用 |
| --- | --- |
| A/B/C 下拉 | 切换方案（**结构不同**：侧栏/顶部 tab、控制台页面/弹窗、行高、圆角、阴影、批量条形态） |
| 暗/亮 | 切换主题（默认亮色，符合已定决策） |
| 加载态 | 文件列表切换到骨架屏 |
| 状态演示 | 控制台在 数据 → 空态 → 错误态 → 加载态 之间循环 |
| 登录页 | 预览登录 / 注册 / 凭据结果三态 |
| 会话过期 | 切换 401 过期 banner（写操作暂停） |
| 上传队列 | 打开多文件队列（暂停全部/续传/重试/清理/并发） |
| 分享页 | 公开 `/s/<token>` 页面（有效 ↔ 失效） |
| 首次引导 | 3 步引导（凭据 → 卷 → 上传） |
| 只读卷 | 只读卷 banner + 写操作禁用 |
| 预览 | 视频 / 图片 / 文本三种预览（含控制条与画质切换） |
| 错误页 | 404 / 500 / 离线 三种错误页 |

顶栏：语言切换（中/英）、账户菜单；手机端：下拉刷新 + 行操作底部面板。

控制台「通知」分区：渠道卡 + 告警规则 + 最近投递；「巡检」分区：统计 + 不一致项 + 修复；「接入」分区：WebDAV/S3/CLI 信息与接入审计。
| 密度 | 紧凑 ↔ 舒适（行高 +10px） |
| 组件库 | 打开设计系统页（色板/字阶/间距/按钮态/输入校验/徽标/进度/反馈四态/危险确认） |
| `?` | 快捷键帮助 |

手机端（≤640px）：顶部 tab 隐藏，改用底部导航（文件/传输/回收站/控制台）；文件列表转卡片行，网格 2 列。

键盘：`⌘K` 命令面板、`/` 搜索、`g f/t/r/c` 跳转、`j/k` 行焦点、`x` 选中、`Enter` 详情、`Esc` 逐层关闭。
深链：`#/console/<section>`，云端任务支持 `?status=&volume=&page=`。

## 导航约定

- 侧栏只有**一个**「控制台」入口；12 个分区在控制台内部导航，不重复出现在侧栏；
- 打开控制台时，外层入口只有弱提示（`data-open`），当前态只给内部当前分区；
- 手机端（≤640px）用底部导航，顶部 tab 隐藏。

## 三套方案的结构差异（不是配色）

| 轴 | A 工程控制台 | B 运维仪表盘 | C 精修既有 |
| --- | --- | --- | --- |
| 导航 | 侧栏 212px | 侧栏 236px | 顶部 tab，无侧栏 |
| 控制台 | 页面内 | 弹窗 1180×760 | 弹窗 1229×736 |
| 行高 | 35px | 45px | 57px |
| 卡片圆角 | 8px | 12px | 8px |
| 卡片阴影 | 无（仅边框） | shadow-1 | shadow-1 |
| 批量操作 | 底部浮动条 | 卡片顶栏 | 现状黄色条 |

## 设计覆盖审查

`design-coverage-review.md`：把产品源码功能面（68 项 parity）逐项对齐设计稿，
记录 7 项功能缺口、4 项缺陷与 3 项明确不做的理由。结论：**68/68 有对应交互**。

## 自检

```bash
# 1) WCAG 对比度（6 套主题 × 13 组配对 + 状态 pill/表头/批量条，要求 0 失败）
python docs/designs/mockups/audit_contrast.py

# 2) 结构探针（headless Chrome，读取 rail/row/radius/shadow/console）
chrome --headless --disable-gpu --window-size=1500,950 --dump-dom file:///$PWD/docs/designs/mockups/webui-v2-prototype.html

# 3) 全状态结构审计（57 状态 × 1500/1280/1024/768/390）：多选中/溢出/裁切/命中区/遮挡
#    详见 ui-audit.md

# 4) 按状态批量截图（输出到 %TEMP%/webui-shots）
python docs/designs/mockups/shoot_states.py
```

修改 token 后必须重跑对比度审计；修改布局后必须重跑结构探针与溢出检查。

## 查看文件与 Meta

- **单击行**：只选中；**单击文件名/缩略图**：预览（视频/图片/文本）；**双击行**：右侧检查器（概览）；
- **右键 / 行尾 ⋯**：预览、详情/Meta、下载、重命名、分享、复制路径、删除；
- 检查器 5 页签：概览 / 分块（可重试）/ Meta（JSON 复制、下载、刷新）/ 版本 / 分享；
- 键盘：`Space` 预览、`Enter` 详情、`m` Meta、`⌘C` 复制路径、`Shift+勾选` 区间选择。

## 数据脱敏（强制）

原型与文档中的所有示例均为**占位数据**，不含真实用户名、文件名、番号、凭据、地址：

| 类型 | 占位形式 |
| --- | --- |
| 文件名 / 番号 | `EXAMPLE-001.mp4` … `EXAMPLE-301` |
| 用户 / Owner | `demo`（头像 `DM`） |
| 凭据 | `skey-example01..09`；Secret 为 `example-secret-not-a-real-key` |
| 主机 / 端口 | `sproxy.example.com:8443`；节点 `192.0.2.11:8443`（TEST-NET-1） |
| 校验值 | `example…checksum` / `EXPECTED-CHECKSUM` / `ACTUAL-CHECKSUM` |
| 邮件 / Webhook | `ops@example.com`、`https://hooks.example.com/...` |

提交前扫描（应无输出）：

```bash
grep -rnoE "skey-[0-9a-f]{6,}|[0-9a-f]{32,}|10\.[0-9]+\.[0-9]+\.[0-9]+|sproxy\.local" docs/designs/
```

## 已知边界

- 数据全部为假数据（`EXAMPLE-*` / `EXAMPLE-*` 占位），落地时字段名与错误分类必须对齐后端；
- 「网格视图」「密度切换」「深链筛选」「拖拽上传」属**新增能力**，不在 `webui-parity-matrix.md`；
- 控制台 12 个分区均已画出，但表单校验、危险操作确认只是交互示意，不代表后端约束；
- 移动端（≤640px）为列表/卡片自适应布局，未做原生手势与 PWA 能力。
