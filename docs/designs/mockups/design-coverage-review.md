## 3. P2 缺陷（对抗审查中发现）

| # | 缺陷 | 证据 | 修复 |
| --- | --- | --- | --- |
| P2-1 | **表头 HTML 损坏**：i18n 替换把属性写到 `>` 之后，页面直接显示 `data-i18n="th.name" data-sort="name" …` 文本，且排序不生效 | DOM 探针 `th.outerHTML` 显示 `<th> data-i18n=…`；`th[data-sort]` 查询为 null | 重写 thead；审计新增 **leaked-attr** 检查（`data-i18n=` / `data-sort=` / `aria-sort=` / `data-dialog=` 出现在可见文本即失败） |
| P2-2 | 连接设置缺「走隧道（调试）」 | 产品 `use-tunnel-checkbox` | 连接设置对话框补开关 + 生产禁用提示 |
| P2-3 | 无自动刷新开关；无最近操作记录 | 产品 `CONSOLE_TAB_KEY` / `sproxy_ct_actions`（sessionStorage） | 云端任务补自动刷新 pill（开关）+ 「最近操作」按 sessionStorage 记录重试/取消/批量操作 |
| P2-4 | 操作日志渲染用 `innerHTML` 拼接文件名（潜在注入） | 文件名可含 `< > &` | 改为 DOM 构建 + `textContent`，杜绝注入 |

## 4. 四维度审查

| 维度 | 检查结论 |
| --- | --- |
| 正确性 | 6 类交互探针 12/12 通过（卷切换、云端批量、按卷筛选、同步/组/归档对话框、快捷键、批量删除确认）；排序实测 `aria-sort=ascending` 且重排 |

| 安全性 | 凭据 Secret 全程掩码；危险操作需输入名称或二次确认；日志渲染改 `textContent`；分享密码错误行内提示 |
| 可维护性 | token 单一定义（颜色/结构分离）；组件类复用；自检脚本可重复（对比度 / 结构探针 / 溢出 / 交互 / leaked-attr） |

## 5. P3：明确不做（及理由）

| 项 | 理由 |
| --- | --- |
| 文件页独立「搜索结果页」 | `⌘K` 分组搜索已覆盖同一路径；再做一个页面属重复入口 |
| 通知模板编辑器 | 需后端模板变量契约（不臆造变量名），当前产品未暴露模板 API |
| 多用户权限矩阵 | 产品只有单 Owner + `api_keys`，没有角色/权限模型可对齐 |

## 7. 残余风险（实现前必须确认）

1. 同步任务的字段名与策略枚举需与后端 API 对齐（当前按产品既有 7 字段设计）；
2. 云端任务批量接口（重试/取消）是否支持批量语义，需后端确认；
3. 组创建的任务清单格式（链接 / 任务 id 混排）需后端校验规则；
4. 卷选择的「全部卷 / auto」语义需与 `/api/files` 的 subdir+volume 参数对齐。
