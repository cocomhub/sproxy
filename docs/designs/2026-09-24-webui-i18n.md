# WebUI i18n 多语言设计（S4-H1，roadmap 11.10-H1）

## 背景与目标
- 现状：`web/static/index.html` `<html lang="zh-CN">` 硬编码，全部静态文案（按钮/占位符/弹窗标题）为中文；`web/static/app.js`（149 函数）动态文案（toast/confirm/prompt/空态）全部中文，无 i18n 框架。
- 目标：轻量 i18n（**零框架**）——新增 `web/static/i18n.js`，支持 zh/en 双语；**zh 为默认与兜底**，保证既有中文 UI 零回归。
- 范围：先覆盖 index.html 全部静态文案 + app.js 高频动态文案（toast/confirm/prompt/空态/面板加载占位），**不追求 100%**（低频弹窗/表格内文案可后续片补）。

## 组件与接口（web/static/i18n.js，全局 `I18N`）
1. **字典**：`I18N.dicts = { zh: {...}, en: {...} }`，key 为语义 ID（如 `upload_files`、`confirm_delete`），**zh 值逐字保留现状文案**；en 为新译。
2. **`I18N.t(key, vars)`**：查当前语言 → 缺 key 回落 zh → 仍缺返回 key 原文（可见、可修）；支持 `{name}` 插值（`confirm_delete: "确认删除 \"{name}\"?"`）。
3. **`I18N.lang()` / `I18N.setLang(l)`**：读优先级 `localStorage['sproxy_lang']` → `navigator.language`（`zh*`→zh，其余→en）→ 默认 `'zh'`；setLang 写 localStorage、更新 `<html lang>`、执行 `applyStaticI18n()`、派发 `i18n:changed` 事件（app.js 监听后重渲染动态视图）。
4. **`I18N.applyStaticI18n()`**：遍历 `[data-i18n]`（textContent）与 `[data-i18n-placeholder]`（placeholder 属性）批量替换；同时设 `document.documentElement.lang`。
5. **`I18N.fmt(tpl, vars)`**：纯函数插值（t() 内部复用，单测直测）。

## index.html 改造
- 静态文案逐节点加 `data-i18n="<key>"`（标题、tab、按钮、label、placeholder 等全部静态节点；option 文案同法）。
- 语言切换器：auth-bar 追加下拉/双按钮（zh | EN），`change` → `I18N.setLang()`。
- 脚本顺序：`i18n.js` 置于其它脚本**最前**（app.js 之前），DOMContentLoaded 时执行 `applyStaticI18n()`。
- CSP 兼容：`script-src 'self'` 已满足（同源静态文件），无需改服务端头。

## app.js 动态文案改造
- 高频调用点统一 `I18N.t()` 包裹：`showToast(...)` 全部文案、`confirm/prompt` 骨架（文件名等用户数据**不翻译**，仅作文本插值变量）、`refreshList/searchFiles/showStats/showHub/showAudit` 等空态与加载占位、`updateBatchToolbar` 计数文案。
- 渲染辅助（build*Html 经 app-render.js 输出）中的高频文案优先包 t()；低频列表列头等标记为后续片。
- 语言切换后：监听 `i18n:changed` 的视图（当前列表/监控面板）重拉重渲染；未监听的重进页面生效（v1 接受）。

## 数据流
1. 首次加载：i18n.js → `lang()` 探测 → DOMContentLoaded `applyStaticI18n()` 替换静态节点。
2. 交互：`setLang('en')` → localStorage 持久化 → 静态重替换 + `i18n:changed` → app.js 动态视图重渲染。
3. 刷新：localStorage 优先命中，语言不丢。

## 错误处理
- 字典缺 key：`t()` 回落 zh → 返回 key 原文（页面可见占位，便于定位漏译）；**en 缺 key 时 zh 兜底保证可读**。
- localStorage 不可用（隐私模式）：try/catch 回落 `navigator.language`。
- 插值缺变量：保留 `{name}` 原样（不 panic，测试断言该行为）。

## 测试与变异点
- **node --test 单测（web/static/i18n.test.mjs，登记 Makefile web-test，R10）**：
  1. zh/en 字典**键集完全一致**（深比较）——变异：删 en 任一 key → 红；
  2. `t()` 命中/回落 zh/返回 key 原文 三态——变异：删回落逻辑 → 红；
  3. `fmt()` 插值、缺变量、多变量、XSS 无注入（值经 escHtml 由调用方负责）——变异：改插值实现 → 红；
  4. `lang()` 优先级（localStorage > navigator.language > 默认 zh）——变异：颠倒优先级 → 红。
- **Playwright e2e（web/e2e/ 新增 spec，沿用现有装配）**：
  1. 默认 zh：断言「上传文件」「刷新列表」可见（同时是既有 e2e 的零回归护栏）；
  2. 切换 en：断言 "Upload"/"Refresh" 出现；
  3. 刷新后语言保持（localStorage 持久化）；
  4. 变异：摘掉某元素 `data-i18n` → 切 en 后该元素仍中文 → 红。

## 片划分
- **片 1**：i18n.js 核心（字典骨架 zh=en 键集一致 + t/fmt/lang/setLang/applyStaticI18n）+ node 单测 + Makefile web-test 登记（R10 门禁闭环）。
- **片 2**：index.html 全部静态节点 data-i18n 化 + 语言切换器 + Playwright 语言切换 e2e。
- **片 3**：app.js 高频动态文案 t() 化 + 相应单测/e2e 补充（含 `i18n:changed` 重渲染接线）。

## 风险与零回归
- **默认仍 zh**：未显式切换（localStorage 无值）且浏览器非中文时按简报走 navigator.language → en；若需严格零回归可先默认 zh、仅 localStorage 驱动（实施时二选一，e2e 锁定行为）。
- 机械改写面大：zh 值**逐字保留**现状文案（构造上不变），既有中文 e2e 断言天然继续通过。
- 新增 JS 文件必须进 Makefile web-test，否则 R10 门禁红。
- CSP `script-src 'self'`：i18n.js 走嵌入式 static FS，无需放宽。
